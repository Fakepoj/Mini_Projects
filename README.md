# Python Mini Projects

A collection of Python exercises and mini-projects developed while building practical programming, problem-solving, and software engineering skills.

## About

This repository documents my progression through Python programming, from fundamental concepts to functions, exception handling, object-oriented programming, and practical problem solving.

The projects were developed as part of my ongoing software engineering training.

## Projects

### Age Status Detector

A simple Python program that determines an age category based on user input and demonstrates conditional logic.

**Concepts:**
- User input
- Integer conversion
- Conditional statements
- Comparison operators

---

### Budget Analyser

A program that compares item prices against a specified budget and identifies affordable items, total required budget, and items that cannot be afforded.

**Concepts:**
- Lists
- String parsing
- Loops
- Conditional logic
- Counters
- Accumulation
- User input

---

### Bank Account — Object-Oriented Programming

A basic object-oriented Python exercise demonstrating the creation and manipulation of `BankAccount` objects.

**Concepts:**
- Classes
- Objects
- Constructors
- Instance attributes
- Object state
- `__init__`

---

### Coffee Order Calculator

A simple program that calculates the total cost of different coffee orders and applies a discount when the order meets a specified threshold.

**Concepts:**
- Variables
- Arithmetic operations
- Floating-point numbers
- User input
- Conditional statements
- Formatted output

---

### FizzBuzz

A Python implementation of the FizzBuzz problem using a reusable function and iteration.

**Concepts:**
- Functions
- Parameters
- Return values
- Loops
- Modulo operator
- Conditional logic

---

### ID Input Validator

A simple input-validation exercise that demonstrates exception handling when converting user input into an integer.

**Concepts:**
- User input
- Type conversion
- `try` / `except`
- `ValueError`
- Error handling

> Note: This exercise validates whether an input can be interpreted as a whole number. It is not an authentication or identity-verification system.

---

### Coffee Size and Toppings

A function-based exercise that accepts a coffee size and a variable number of toppings.

**Concepts:**
- Functions
- Parameters
- Variable-length arguments (`*args`)
- Conditional statements
- Iteration
- Docstrings
